# 文章工作台 · Web 2.0

[在线使用](https://shimt9105-eng.github.io/article-workbench/)

横向三步 Tab：找对标 → 开始创作 → 提意见。开始创作沿用编辑2号的任务列表、文章预览、System、模型版本与意见布局。

1. 注册 / 登录工作台。工作台密码仅用于文章工作台，与公众号登录密码无关。
2. 找对标：输入主题、写作方向，明确选择“来源 / 模型”；搜索真实微信文章后，AI 推荐最多3篇并说明理由。搜索、推荐分别可重试。选定后转入开始创作；读取不到全文时粘贴完整正文。
3. 开始创作：选择写作模型，上传 `.docx` 或粘贴资料正文，提供对标全文与原始随笔。沿用编辑2号的 System、整篇 HTML 输出和多模型独立版本。
4. 提意见：选择文章文字、写修改意见，按同一固定依据更新全文。正文可直接编辑并自动保存，过期版本拒绝覆盖。
5. 连接设置：每人绑定自己的公众号。绑定发布接口用 **AppID + AppSecret**，并配置服务器 IP 白名单与接口权限；不收集公众号登录密码。
6. 发送到公众号草稿箱：选择已完成版本，分别生成封面，上传正文图片并保存草稿。查看发送记录，再到微信公众平台检查和正式发布。

## 部署结构

- `web/`：GitHub Pages 静态网页；不含任何服务密钥。
- `backend/`：CloudBase HTTP 云函数，独立的 `article_web_*` 集合保存网页版状态。
- `tests/`：内存隔离测试与浏览器验收 fixture；不会调用真实模型、TikHub 或微信。
- `deploy.py`：从已有工作台的配置表同步启用模型和搜索配置，部署到已有 CloudBase。密钥通过临时配置进入后端，临时文件自动删除。
- `.github/workflows/pages.yml`：main 分支推送后先运行测试，再发布网页。

默认共用站点所有者的 API 配置，每账号每日30次、全站每日300次。搜索、AI 推荐、每个模型生成/重写、每张封面分别计次；失败调用也计入。用户可填写自己的 API 配置，但仍受站点额度保护。公开注册具有单账号限频和全站总额限制；管理员需根据实际使用量调整额度。

## 本地检查

在项目根目录：

```sh
cd outputs/文章工作台GitHub网页版/script
npm ci --prefix backend
npm test
node tests/qa-server.js
```

隔离浏览器验收入口：`http://127.0.0.1:4382`。预置测试用户名 `qa_user` 与测试密码 `test-password-123` 只存在 fixture；与生产账号无关。

## 维护后端

在项目根目录运行：

```sh
python3 outputs/文章工作台GitHub网页版/script/deploy.py
```

部署脚本需要本机已授权的 DWS、CloudBase CLI 和已有文章机器人配置。换电脑时重新安装工具、登录并配置路径；不复制真实用户状态。首次部署创建的加密与签名密钥保存在 `$HOME/.config/article-workbench-web/backend-secrets.json`，权限600。保留该文件，后续部署复用，否则已存的公众号凭据将无法解密。不要把它放入仓库或 outputs。

模型列表按“来源 + 模型名 + 记录 ID”区分，部署时同步启用记录。网页不能调用本机 Codex CLI；在线可用协议为 OpenAI Chat、OpenAI Responses、Anthropic Messages。原始编辑2号生成 core 与资料图片插入文件完整复用。

网页版不自动使用桌面应用真实任务或私有文档登录态。本地 `.doc` 需先转成 `.docx`；钉钉、石墨私有资料需要粘贴正文或上传 Word。微信公众号限制全文读取时，必须粘贴全文，不能使用摘要替代。

## 数据与失败恢复

用户密码使用随机盐 scrypt；公众号和自用 API 凭据用 AES-256-GCM 加密保存。前端只显示配置状态、模型公开元数据和 AppID 尾号。12小时会话存入当前浏览器标签的 sessionStorage，退出即使会话失效。

每个模型版本拥有 revision 与 attempt ID；生成不会由旧结果覆盖新版本。生成期间禁止编辑；正文保存校验来源 revision。发送按“账号、任务、模型、公众号、正文哈希”去重。微信接收结果不确定时禁止自动再发，先检查公众号草稿箱。

只有用户点击发送才调用草稿接口；不提供自动正式发布。部署与验收不会替用户发文章。

管理员维护密钥、额度或 API 提供方信息后运行部署脚本。当前无需桌面程序运行即可使用网页。删除或回滚任何真实文章状态前先导出与校验备份，不覆盖已有桌面状态。

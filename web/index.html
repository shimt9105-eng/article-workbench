连接设置 / 绑定公众号

使用 AppID + AppSecret 绑定发布接口

不需要填写公众号登录账号或密码。当前仅支持保存草稿，正式发布由你在微信后台完成。

  1. 使用管理员账号打开微信开发者平台，进入“我的业务 → 公众号/服务号”，选择你自己的公众号，在开发信息中查看 AppID 和 AppSecret。
    查看官方迁移与配置指引 · 公众号开发信息直达
    直达链接对应指定公众号；绑定其他公众号时，请从“我的业务”选择你自己的公众号。
  2. 确认账号具有草稿箱、永久素材和图片上传接口权限。接口权限不足时无法写入草稿。
  3. 将服务器出口 IP 加入公众号 IP 白名单。点击下方验证后，若微信提示 40164，这里会显示需要加入的 IP。
  4. 填写下方资料，点击“验证并绑定”。凭据加密保存到你的访客空间，不返回浏览器、不进入 GitHub。
  5. 选择文章版本，生成封面后发送到草稿箱；在微信后台检查排版，再自行发布。
